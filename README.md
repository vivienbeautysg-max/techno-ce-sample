# Techno CE — Website Sample

Static one-page site for **Techno CE Pte Ltd** (UEN 200210947C), Singapore civil engineering firm.

Sample build for client review. Not affiliated; client confirmation pending.

- `index.html` — single-page editorial layout (Variant A, primary)
- `style.css` — Industrial Editorial design system + premium motion layer
- `app.js` — core JS (counters, hero slideshow, showcase tabs, register modal, burger)
- `premium.js` — premium motion: intro preloader, scroll progress, reveal choreography, hero parallax, scrollspy, magnetic buttons, custom cursor
- `img/` — curated photography
- `v2/` — Variant B, lighter alternate design (not yet updated with the 2026-06-25 feedback)

## Motion
Dependency-free, GPU-friendly, and fully `prefers-reduced-motion`-safe (reduced-motion
users get instant content, no looping). If JS fails to load, content is never hidden.
